## 실험 운영 원칙

### 기준 문서와 현재 상태

- 실제 실행 수치는 `configs/initial.json`, 초기 설정 요약은 `docs/EXPERIMENT_GUIDE.md#initial-settings`를 기준으로 합니다.
- 선택 근거와 당시 사용자 답변은 `reports/decisions/scope.md`, `features.md`, `training.md`의 DEC-001~023 절에 보존합니다. 과거 결정의 미정·검토 대기 표시는 당시 상태이며 후속 결정으로 대체된 내용을 현재 미정으로 해석하지 않습니다.
- 팀 확인과 1차 실행 승인은 DEC-023, 실제 9개 조합 결과는 `reports/experiments/EXP-001_first-run.md`에 있습니다. 현재 진행 상태와 다음 작업은 루트 README에서 관리합니다.
- 결과를 보고 조정할 수 있는 초기 세부값 선정은 DEC-022에서 위임받았습니다. 아래 데이터·평가 원칙의 변경까지 위임받은 것으로 해석하지 않습니다.

### 데이터

- 원본은 보존하고 가공 결과를 분리합니다. KBO 2026년 행은 이번 실험에서 제외합니다.
- 경기 기록 없음과 실제 비경기일을 구분합니다. 미검증을 임의로 0으로 바꾸지 않습니다.
- 예정/실제 시작, 취소·연기, 하루 여러 경기 처리와 결합 키를 확인합니다.
- 최종 관중·점수·실제 종료·사후 취소 여부를 전날부터 알았던 정보처럼 입력하지 않습니다.
- 당시 일정을 복원하지 못하면 사후 기록 기반 실험임을 표시합니다.
- 자료 공개 지연을 확인하기 전 운영 가능성이 검증됐다고 주장하지 않습니다.
- 공휴일은 주말과 구분하며 공휴일 참조 목록으로 입력을 생성합니다.

### 평가

- 시간순 학습·검증·최종 평가를 사용합니다.
- 정규화·결측 대체·평균 기준은 학습 자료에만 맞춥니다.
- 모델에 같은 평가 날짜와 이용 가능한 정보를 제공하고 입력 표현 차이를 기록합니다.
- 모델 선택·튜닝은 검증 데이터로 합니다. 최종 평가를 보고 다시 선택하면 별도 탐색임을 명시합니다.
- 기존 탐색 날짜 2025-09-25·26·27·28·30 및 2025-10-01은 최종 평가 집계와 분리하도록 설계합니다.
- 승차·하차, 전체·월별·note 상태별 성능과 표본 수를 보고합니다. 기록 없는 날짜를 확정 비경기일로 표시하지 않습니다.
- 데이터 보충 후 재실험 시 데이터 버전과 조건 차이를 기록합니다.

### 변경 순서

관찰 → 원인 가설 → 선택지·장단점 설명 → 사용자 답변·결정 기록 → 승인된 설정 실행 → 실제 결과·한계 기록.

DEC-022의 위임 범위에서는 에이전트가 초기값과 조정 가능한 세부값을 선정하고 이유·조건을 기록할 수 있습니다. 기존 확정값은 1차 기준으로 유지하며 후속 튜닝은 검증 근거를 남깁니다. 데이터 범위·입력 정보·분할·예측 목표·평가 원칙의 변경은 이 위임에 포함하지 않습니다.

학습으로 갱신되는 내부 가중치와 사람이 부여하는 손실 가중치·팀 인기도 점수는 구분합니다. 후자는 사전 협의 대상입니다.

## 1차 설정과 팀 확인

2026-11-02에 결정한 1차 설정입니다. 2026-11-03 사용자에게 팀 확인 완료를 전달받아 DEC-023에 기록했고, 아래 설정으로 9개 조합 학습·검증을 완료했습니다. 하반기 최종 평가는 미실행입니다. 후속 실험은 별도 설정·실험 기록으로 구분하며 이 표는 1차 기준을 유지합니다.

| 모델·입력 기간 | RF·MLP·LSTM × 3·7·14일 | 사용자 확정 |
| 예측 목표 | 전날 기록 확보 가정, 다음 날 18시간 승차·하차 36개 | 사용자 확정 |
| 분할 | 2024 학습 / 2025 상반기 검증 / 하반기 평가 | 사용자 확정 |

| 보조 평가 | 승차·하차 RMSE, 월별·note 상태별 성능·표본 수 | 사용자 선택·팀 확인 완료 |
| 달력 입력 | 요일·월·공휴일 여부(B안), DEC-007 | 사용자 선택·팀 확인 완료 |

| RF 분할 기준 | squared_error, 기타 세부값 DEC-022 | 위임에 따른 선정·팀 확인 완료 |

# 실험 운영과 주의사항

## 합의 완료

DEC-010: 경기 1·2의 홈팀·원정팀은 원-핫 인코딩합니다. 범주는 학습 자료로만 구성하며 기록 없음과 학습에 없던 팀을 구분합니다. 사용자 선택 완료·팀 검토 대기입니다.
DEC-009: 예정 시각은 자정부터 분과 시각 존재 표시를 함께 제공합니다. 빈칸은 계산용 0·표시 0이며 비경기일 확정값이 아닙니다. 정규화 방식은 미정이고 팀 검토 후 구현·학습합니다.
DEC-008: 기본 일정(수집 기록 유무·건수·예정 시각)과 홈팀·원정팀 입력을 사용자 선택 완료, 팀 검토 대기입니다. 인기도 점수와 note는 입력에서 제외합니다. 범주·빈칸 표현은 아직 미정입니다.
DEC-005: 1차 행사 정보는 야구에 집중하고 다른 행사 추가는 향후 발전 계획으로 분리합니다. 전체 날짜를 사용하는 기존 분할은 유지합니다.
2024~2025년 자료 사용. 2026-11-04까지 1차 실행 후 부족한 자료 보충. 여러 모델 비교 후 최종 모델 선택. 모델의 이유·장단점과 설정·가중치의 의미를 설명하고 사용자 답변 후 실행.

1차는 2호선, 학습 모델은 랜덤포레스트·MLP·LSTM으로 확정했습니다. 추가 학습 모델은 보류합니다. 단계마다 설명하고 협의하며 진행합니다. 근거는 `reports/decisions/DEC-001_initial-model-scope.md`에 기록했습니다.

분할은 DEC-004에서 승인: 2024년 학습 / 2025년 상반기 검증 / 하반기 최종 평가. 경기 기록 없는 날은 미확인으로 유지합니다. 공통 입력 확보와 탐색일 제외 후 대상 수는 352/181/178일입니다.

## 미확정

DEC-006: 전체 검증 날짜의 승차·하차 평균 MAE를 주 지표로 사용자 선택 완료, 팀 검토 대기입니다. RMSE·월별·note 상태별 성능을 함께 보고합니다. 설정 전체 결정과 팀 검토 후 학습합니다.

입력 변수, 기준 예측 구성, 경기 전후 평가 시간대, 모델별 설정, 결측 처리의 구체적인 구현. 계획서의 미승인 수치는 후보입니다.

과거 입력 기간은 DEC-003에서 승인: 세 모델 각각 3일·7일·14일을 비교하는 9개 기본 조합입니다. 학습은 아직 실행하지 않았습니다.

예측 시점·출력은 DEC-002에서 승인: 오늘 23~24시까지 기록 확보를 가정해 다음 날 06~24시 승차·하차 36개 값을 예측합니다. 실제 자료 공개 시점은 미검증입니다.

## 데이터

- 원본은 보존하고 가공 결과를 분리합니다. KBO 2026년 행은 이번 실험에서 제외합니다.
- 경기 기록 없음과 실제 비경기일을 구분합니다. 미검증을 임의로 0으로 바꾸지 않습니다.
- 예정/실제 시작, 취소·연기, 하루 여러 경기 처리와 결합 키를 확인합니다.
- 최종 관중·점수·실제 종료·사후 취소 여부를 전날부터 알았던 정보처럼 입력하지 않습니다.
- 당시 일정을 복원하지 못하면 사후 기록 기반 실험임을 표시합니다.
- 자료 공개 지연을 확인하기 전 운영 가능성이 검증됐다고 주장하지 않습니다.
- 공휴일은 주말과 다릅니다. 현재 표에는 주말 열만 있습니다.

## 평가

- 시간순 학습·검증·최종 평가를 사용합니다.
- 정규화·결측 대체·평균 기준은 학습 자료에만 맞춥니다.
- 모델에 같은 평가 날짜와 이용 가능한 정보를 제공하고 입력 표현 차이를 기록합니다.
- 모델 선택·튜닝은 검증 데이터로 합니다. 최종 평가를 보고 다시 선택하면 별도 탐색임을 명시합니다.
- 기존 탐색 날짜 2025-09-25·26·27·28·30 및 2025-10-01은 최종 평가 집계와 분리하도록 설계합니다.
- 승차/하차, 전체/경기일/비경기일 성능과 표본 수를 함께 보고합니다.
- 데이터 보충 후 재실험 시 데이터 버전과 조건 차이를 기록합니다.

## 변경 순서

관찰 → 원인 가설 → 선택지·장단점 설명 → 사용자 답변·결정 기록 → 승인된 설정 실행 → 실제 결과·한계 기록.

학습으로 갱신되는 내부 가중치와 사람이 부여하는 손실 가중치·팀 인기도 점수는 구분합니다. 후자는 사전 협의 대상입니다.

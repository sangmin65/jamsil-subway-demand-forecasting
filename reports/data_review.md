## 수집 출처와 크롤러 검토

2026-11-02. 사용자가 전달한 팀원 답변 및 추가 파일을 읽기 전용으로 검토했습니다. 노트북을 실행하거나 재수집하지 않았습니다.

### 사용 제한

`kbo_jamsil_all_columns(2024~2026).csv.xlsx`는 **URL만 참고**합니다. 사용자는 이 파일의 경기 취소 표시가 실제 취소를 의미하지 않는다고 전달했습니다. 다른 열을 정답·상태 근거로 채택하지 않습니다. 원본 CSV의 비고(note)와 Excel의 상세 상태를 혼동하지 않습니다.

### 팀원에게 확인된 내용

- 시범경기는 제외, 정규시즌 중심 자료입니다.
- 원본 비고의 취소 표기를 통해 취소를 확인하며 취소일도 수집 기록으로 남습니다.
- 연기 경기와 재편성 경기의 연결은 별도로 정리하지 않았습니다.
- 더블헤더는 같은 날짜 두 기록으로 보존되어 복수 경기로 반영됩니다.
- 수집 실패 유무·전수 완전성·전날 일정 가용성은 아직 확인되지 않았습니다.

### 노트북에서 확인한 사실

대상: `kbo_jamsil_full_crawl_colab(2) (1).ipynb`.

- 일정 요청: `https://www.koreabaseball.com/ws/Schedule.asmx/GetScheduleList`.
- 참고 페이지: `https://www.koreabaseball.com/Schedule/Schedule.aspx`.
- 구장 열에 '잠실'이 포함된 행으로 필터링합니다. 팀 이름만으로 고르는 코드가 아닙니다.
- MONTHS는 3~10월입니다. 1~2월·11~12월을 조회한 코드가 아닙니다.
- 전달 노트북의 YEARS는 **[2023]**이지만, 이후 사용자가 연도별 실행 사실을 확인했습니다. 연도만 바꿔 재사용한 것으로 확인되었으며 아래 ZIP 대조로 2024~2025년 응답도 확인했습니다.
- SERIES_CODES는 `0,9,6,3,4,5,7`이며 주석은 정규+포스트시즌 의도를 명시합니다. 이것만으로 실제 두 해의 포스트시즌 전수 수집을 증명하지 않습니다.
- 월별 요청 실패는 errors에 모아 `schedule_errors.csv`로, 상세 실패는 `detail_errors.csv`로 저장하는 코드입니다. 최초 노트북 검토 때는 로그가 없었으나 이후 ZIP에서 확인했습니다. 상세 내용은 아래 ZIP 대조 절에 있습니다.
- 짧은 행은 건너뛰며 빈 결과를 실패로 판정하는 별도 검증은 없습니다. 오류 로그가 비어도 완전성을 보장하지 않습니다.
- `drop_duplicates()`는 전체 열 기준입니다. 날짜만으로 더블헤더를 합치는 코드는 아닙니다.
- `scheduled_start_time`은 일정 표에서 읽습니다. 사전 발표 당시 스냅샷을 보관하는 코드는 아닙니다.

### 상세 취소 표시의 오류 가능성

`parse_detail`은 전체 HTML을 텍스트로 바꾼 뒤 어디든 '경기취소'가 있으면 gamecenter_status를 경기취소로 설정하고, 그다음 경기종료를 검사합니다. 현재 경기의 상태 요소로 범위를 한정하지 않아 다른 요소·숨겨진 문구가 섞일 가능성이 있습니다. 실제 HTML 대조는 하지 않았으므로 구체적인 오표시 원인을 확정하지 않습니다. 사용자 지시에 따라 해당 Excel 상태는 사용하지 않습니다.

## 원천 ZIP과 전달 CSV 대조

2026-11-02. 사용자는 노트북을 연도별로 실행했음을 확인했습니다. 현재 YEARS=[2023]을 전달 CSV의 연도 오류로 판단하지 않습니다.

### 확인 결과

- 입력 ZIP: `kbo_jamsil_data.zip`. 475개 항목, 압축 무결성 검사 통과. 압축 내부 자료만 읽었으며 노트북·HTML은 실행하지 않았습니다.
- 2024·2025년 3~10월 원본 JSON 16개 모두 존재하고 비어 있지 않습니다.
- JSON에서 잠실 기록을 재추출한 결과 2024년 168건, 2025년 158건, 합계 326건입니다.
- 날짜·예정 시작·구장·비고·홈팀·원정팀을 중복 횟수까지 비교해 전달 CSV와 차이 0건입니다. 짧은 행으로 건너뛴 응답 행도 0건입니다.
- ZIP CSV와 전달 CSV의 2024~2025년 공통 열 값은 모두 일치합니다. 잘못된 `gamecenter_status`는 비교·상태 근거에 사용하지 않았습니다.
- `schedule_errors.csv`, `detail_errors.csv`는 BOM과 줄바꿈만 있으며 기록된 오류가 없습니다.

### 해석

**저장된 16개 원본 응답에서 잠실 기록을 CSV로 옮기는 단계의 누락은 발견되지 않았습니다.** 이는 기존의 단순 빈칸·중복 검사보다 강한 수집 근거입니다. 다만 서버 응답 자체의 완전성이나 쿼리 대회 범위까지 전수 검증한 것은 아닙니다.

노트북은 연도별 실행 시 같은 오류 로그 이름을 덮어쓰므로 빈 로그가 모든 연도 실행의 무오류를 보장하지 않습니다. 현재는 연도별 원본 JSON을 직접 대조한 결과를 근거로 사용합니다.

시범경기 제외, 1~2월·11~12월 미조회, 연기·재편성 연결 미정리, 예측 전날 일정 스냅샷 미검증은 그대로입니다. 따라서 기록 없는 날을 자동으로 실제 비경기일로 변경하거나 두 검증 플래그를 일괄 1로 올리지 않았습니다.

## 현재 경기 상태 판단 원칙

2026-11-02 사용자 전달 팀원 조언:

> gamecenter_status 이건 믿지 말것 그날 있었던 경기 중에 하나라도 취소 되면 취소 취급함 note 만 봐

### 적용

- 경기 상태는 원본 일정의 경기별 `note`를 근거로 판단합니다.
- `gamecenter_status`는 입력·정답·상태별 평가 그룹 구성에서 모두 제외합니다.
- 팀원 설명에 따르면 상세 상태는 같은 날 다른 경기 취소에 영향을 받을 수 있습니다. 노트북이 전체 페이지 텍스트를 검색하는 방식인 것은 확인했지만 HTML에서 구체적인 오표시 경로를 재현한 것은 아닙니다.
- `note`에 '취소'가 있으면 명시적 취소 기록으로 분류합니다.
- `-`는 특이 비고 없음이며, 비고만으로 경기 완료까지 확정하지 않습니다.
- '기타', '그라운드사정' 등 취소 문구가 없는 상태는 원문을 보존하고 별도 미확인으로 둡니다.
- 같은 날짜에 서로 다른 상태가 있으면 혼합 상태로 보존합니다. 한 경기 취소를 날짜 전체 취소로 확장하지 않습니다.
- 기록 없는 날짜는 계속 미확인입니다. 실제 취소 정보가 예측 전날 알려졌는지는 별도 확인 대상입니다.

### 이전 결과와 관계

이전 분할 보고서의 '경기 결과 있음'은 점수·실제 시작 필드 존재를 확인한 **과거 검사 결과**입니다. `gamecenter_status`는 그 집계에도 사용하지 않았습니다. 앞으로 상태별 평가 분류에는 이를 그대로 사용하지 않고 경기별 note 근거를 적용합니다. 분할과 날짜 제외 규칙은 바뀌지 않습니다.

새 집계는 [note 기준 JSON](metrics/note_status_counts.json)에 있습니다. 숫자가 같은 경우에도 '특이 비고 없음'과 '실제 개최 확인'은 의미가 다릅니다.

### 경기 상태별 날짜 수

경기 결과 있음은 원본에 양 팀 점수와 실제 시작이 기록된 경우입니다. 공식 경기 결과와 전수 대조한 것은 아닙니다. 경기 횟수가 아닌 날짜 수이며 상태는 서로 배타적입니다.

| 상태 | 2024년 | 2025년 상반기 | 2025년 하반기 |
|---|---:|---:|---:|
| 전체 | 366 | 181 | 184 |
| 경기 결과만 있음 | 147 | 78 | 65 |
| 경기 결과와 취소·기타 기록 혼재 | 0 | 1 | 0 |
| 취소·기타 기록만 있음 | 17 | 7 | 4 |
| 기록 없음·비경기 확정 불가 | 202 | 95 | 115 |

14일 입력에 맞춰 공통 대상 날짜를 잡으면 학습은 352일입니다. 검증은 이전 구간의 과거 기록을 입력으로 활용할 수 있어 181일입니다. 기존 탐색 6일을 제외하면 최종 평가는 178일, 그중 결과가 기록된 경기일은 59일입니다. 추가 결측 처리 전의 수입니다.

### 시즌 구분의 확인 범위

정확한 시즌/비시즌 일별 라벨은 아직 확정할 수 없습니다. 시범경기·정규시즌·포스트시즌을 구분한 원천 일정의 완전성 확인이 필요합니다. 우선 계절 구성이 한쪽에만 치우쳤는지 확인하기 위해 달력 구간을 집계했습니다. **이 구간은 공식 시즌 라벨이나 승인된 모델 입력이 아닙니다.**

| 달력 구간 | 2024년 | 2025년 상반기 | 2025년 하반기 |
|---|---:|---:|---:|
| 겨울 구간: 1~2월·11~12월 | 121 | 59 | 61 |
| 3월 전환 구간 | 31 | 31 | 0 |
| 4~10월 | 214 | 91 | 123 |

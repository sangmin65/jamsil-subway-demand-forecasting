# EXP-007 모델 용량 비교

로컬 CPU에서 RF 3개, RTX 5060에서 신경망 6개를 학습했다. 기존 모델별 기준에서 한 항목만 바꿨다. 설정은 [DEC-029](../decisions/training.md#dec-029)에 기록했다.

학습은 2024년 352일, 검증은 2025년 상반기 181일이다. 선택 지표는 음수 예측을 0으로 보정한 시간대별 승하차 평균 절대 오차다. 하반기 최종 평가는 실시하지 않았다.

## 모델별 비교

- RF 기준 포함 최선은 잎 크기 3→2, 검증 MAE 255.80명이다.
- MLP 기준 포함 최선은 기존 기준, 검증 MAE 290.31명이다.
- CNN 기준 포함 최선은 기존 기준, 검증 MAE 325.91명이다.
- LSTM 기준 포함 최선은 기존 기준, 검증 MAE 275.65명이다.

RF의 최소 잎 2는 기존 최소 잎 3보다 오차가 0.0693명 줄었다. 두 조건의 차이가 작아 시드 42 한 번으로 안정적인 우열을 판단하기 어렵다. MLP·CNN·LSTM은 폭과 깊이를 바꾼 여섯 조건 모두 기존 모델의 검증 MAE를 넘었다.

LSTM의 기존 32유닛 한 층은 15.75분(1,333에포크), 64유닛 한 층은 16.50분(1,508에포크), 32유닛 두 층은 13.20분(699에포크)에 종료됐다. 두 층 모델은 649에포크에서 최선값을 기록한 뒤 조기 종료돼 총시간이 짧았다. 여섯 신경망 조건 모두 최선 에포크에서 50회가 지난 뒤 종료됐다.

## 비교 범위

- RF는 Windows CPU, 신경망은 WSL GPU에서 모델별 기준과 같은 패키지 버전을 사용했다. RF는 나무 수·깊이·최소 잎 중 하나씩 변경했다. 잎 1·5·10의 기존 비교는 EXP-004에 있다.
- 신경망 학습률 0.003, 배치 16, patience 50, 시드 42. MLP·CNN 최대 1000회, LSTM 최대 2000회. CNN은 헤드 Dropout 0.1, MLP와 LSTM은 0이다.
- 기준과 각 조건의 원본·KBO·공휴일 해시, 대상 날짜, 입력 특성 목록을 확인했다. 기준·신규 저장 모델을 다시 불러와 검증 예측을 확인했다. 신경망의 GPU 가중치 배치를 확인했다.
- 폭과 깊이 조건은 각각 파라미터 수가 다르다. 이 비교는 정해진 구조 변경의 결과이며, 모델 크기를 맞춘 상태에서 폭·깊이 자체의 효과를 분리하는 실험은 아니다. 단일 시드와 같은 검증 기간을 사용했다.
- [RF 조건별 지표](../metrics/capacity_rf_2026-11-06.json)와 [신경망 조건별 지표](../metrics/capacity_neural_2026-11-06.json)에 월별·경기 기록 상태별 결과, 환경, 기준, 실행 시간을 보존했다.
- 로컬 출력 경로는 outputs/capacity-rf-2026-11-06 및 outputs/capacity-neural-2026-11-06이다. 재실행은 tools/run_capacity_gpu.py의 --group rf 또는 --group neural을 사용하고 새 출력 경로를 지정한다.

## 확인 범위

- 입력 원본·KBO·공휴일 해시 및 src 코드 해시가 EXP-001과 동일합니다.
- 4개 조건의 저장된 검증 예측에서 MAE를 재계산했고 보고서와 1e-6 이내 일치했습니다. 학습곡선 길이와 종료 에포크도 일치합니다.
- 학습 코드가 최선 가중치를 복원한 후 저장·검증 예측했습니다. 이번 확인에서 저장 모델을 별도로 다시 로딩해 예측하는 검증은 아직 수행하지 않았습니다.
- MLP 실행 시작 시에는 설정·기록이 미커밋 상태였으며 이후 7860711에 기록됐습니다. LSTM 실행은 해당 커밋에서 시작했습니다. 실제 실행 설정과 코드 해시는 각 로컬 보고서에 보존됩니다.
- 하반기 최종 평가는 실행하지 않았습니다. 최대 에포크와 patience를 동시에 바꾼 결과이며 단일 시드입니다.

# DEC-017: 최대 학습 횟수와 검증 MAE 기준 조기 종료

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 결정

1차 MLP·LSTM은 최대 에포크 수를 제한하고, 검증 MAE 개선 여부에 따른 조기 종료를 함께 사용합니다. 학습 종료 후 검증 MAE가 가장 낮았던 시점의 모델 가중치를 복원합니다. 최대 횟수에 도달하여 종료한 경우에도 동일하게 최선의 검증 모델을 사용합니다.

검증 기준은 DEC-006·DEC-016의 원래 인원 단위 승차·하차 평균 MAE입니다. 2025년 상반기 검증 자료를 사용하며 하반기 최종 평가 자료는 조기 종료에 사용하지 않습니다. 이 방식은 신경망에 관한 결정으로 RF에 자동 적용하지 않습니다.

## 이유와 한계

학습 오차만 계속 낮아지는 과적합과 불필요한 학습을 줄이기 위한 초기 운영 방식입니다. 조기 종료가 과적합 방지나 충분한 수렴을 보장하지는 않습니다. 학습·검증 곡선, 최선 에포크, 실제 종료 에포크, 종료 사유를 기록해 미수렴이나 일시적인 성능 정체를 확인합니다.

## 미정 사항

최대 에포크 수, 개선을 기다릴 횟수(patience), 개선으로 인정할 최소 차이(min_delta), 검증 주기와 동점 처리 등의 세부 기준은 별도 협의합니다. 라이브러리 기본값을 자동 확정하지 않습니다. 최대 횟수까지 성능이 개선되어도 자동으로 학습 한도를 늘리지 않고 결과를 보고 협의합니다.

## 사용자 답변

최대 횟수와 검증 MAE 기준 조기 종료 및 최선 모델 복원 제안에 다음과 같이 답했습니다.

> 응 최대 횟수 조기 종료로 가자

설정 전체 결정과 팀 검토 완료 전 학습하지 않습니다.

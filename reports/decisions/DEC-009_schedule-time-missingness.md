# DEC-009: 예정 시작 시각과 정보 존재 표시

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 결정

경기 기록 1·2 각각 예정 시작 시각을 자정부터의 분으로 표현하고 시각 정보 존재 여부를 함께 제공합니다. 예: 18:30은 1110분과 존재 표시 1. 빈 시각은 계산용 0과 존재 표시 0입니다. 원본 CSV는 수정하지 않고 이후 모델 입력 생성 단계에서 적용합니다.

빈 시각의 0은 실제 자정 경기·경기 없음·취소를 뜻하지 않습니다. 수집 기록 유무·건수와 함께 해석하고 원본의 미확인 상태를 보존합니다. 기록 한 건이면 둘째 시각 정보가 없고, 기록 자체가 없으면 두 시각 정보가 없습니다.

## 사용자 확인

예정 시각의 분 변환, 빈 시각의 계산용 0과 존재 표시, 정규화와의 차이를 설명한 뒤 사용자가 답했습니다.

> 음 확인했어 넣어도 좋을거 같아

## 미확정 범위

분 값을 1440으로 나누는 방식은 설명용 후보이며 아직 승인하지 않았습니다. 팀·달력 범주 인코딩, 학습 손실·모델 설정도 별도 협의합니다. 본 승인을 팀 원-핫 인코딩 승인으로 확대하지 않습니다. 추가 상대 시각 열(`minutes_until_scheduled_start`)은 아직 입력으로 확정하지 않았습니다.

일정의 예측 전날 가용성이 미검증이라는 기존 한계는 유지합니다. 전체 설정의 팀 검토 후 학습합니다.

# DEC-010: 팀 이름 원-핫 인코딩

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 결정

경기 기록 1·2 각각의 홈팀·원정팀을 원-핫 인코딩합니다. 네 필드는 구분하며 세 모델에 같은 범주 정의를 제공합니다. 팀에 임의의 순위·인기도 점수를 부여하지 않습니다.

범주 목록은 학습 자료에서만 구성합니다. `NO_LISTED_RECORD`는 기록 없음 범주로 유지하고, 학습에 등장하지 않은 팀은 별도의 새 범주로 처리합니다. 새 범주와 기록 없음은 구분합니다. 검증·평가 데이터를 보고 범주 목록을 확장하지 않습니다.

## 근거와 한계

팀별 구분에 수치적 크기·간격을 부여하지 않고 해석하기 쉽습니다. 대신 입력 열이 늘며, 새 범주에 대한 별도 학습 사례가 없다면 예측 품질은 보장되지 않습니다. 원-핫 인코딩만으로 드문 팀 조합의 과적합이 해결되는 것은 아닙니다.

## 사용자 답변

> 응 원핫 인코딩으로 가자

팀 범주 표현에 대한 결정입니다. 달력 표현·정규화·모델 구조·손실·학습 설정은 별도 협의하며 전체 설정의 팀 검토 후 실행합니다.

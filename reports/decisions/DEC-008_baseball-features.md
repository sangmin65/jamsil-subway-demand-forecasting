# DEC-008: 기본 일정과 홈팀·원정팀 입력

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 선택한 입력

과거 승하차와 달력 입력에 다음 야구 정보를 추가합니다.

- 수집 기록 유무(`has_kbo_record`)와 건수(`listed_game_count`)
- 경기 기록 1·2의 예정 시작 시각
- 경기 기록 1·2의 홈팀·원정팀

시각·팀의 인코딩, 빈 시각의 계산용 대체값 등 구체적인 표현은 다음 협의 대상입니다. 시각의 여러 중복 표현이나 복수 기록 플래그를 자동으로 모두 추가하지 않습니다.

## 제외와 의미

별도 인기도 점수·팀별 임의 가중치는 사용하지 않습니다. 홈팀은 잠실 홈 구단(LG·두산)을 구분하고 원정팀은 상대 구단을 구분하는 정보입니다. 학습된 차이를 인기도의 인과 효과로 해석하지 않습니다.

note는 사후 상태 분석에 사용하고 모델 입력에서 제외합니다. gamecenter_status, 예측 대상일의 실제 관중·점수·시작/종료 시각, 검증·관리용 열도 입력에서 제외합니다.

has_kbo_record=0은 실제 경기 없음이 아니라 수집 목록에 기록 없음입니다. 건수에는 취소 기록이 포함됩니다. 번호 1·2는 예정 시각 순서이며 공식 경기 번호가 아닙니다. 전날 일정 가용성은 아직 검증되지 않았으므로 사후 수집 일정에 기반한 실험이라는 한계를 명시합니다.

## 사용자 확인

'기본 일정 + 홈팀·원정팀, 인기도 점수 제외' 제안에 사용자가 '응 그게 좋을거 같아'라고 답했습니다. 잠실 홈팀 구조에 대한 추가 설명 후 'ㅇㅋ 그럼 진행해도 될 거 같아.'로 확인했습니다.

실제 모델 학습은 전체 설정 결정과 팀 검토 후 진행합니다.

# DEC-014: 1차 신경망 과거 승하차 입력 표준화

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 결정

1차 MLP·LSTM의 과거 승차·하차 입력은 승차와 하차를 각각 표준화합니다. 변환은 `(인원 - 학습 평균) / 학습 표준편차`입니다. 평균·표준편차는 2024년 학습 자료에서만 계산하고, 검증·평가 자료에는 저장한 기준을 그대로 적용합니다. 시간대별 별도 스케일러를 자동 추가하지 않습니다.

이번 승인은 과거 승하차 입력에 한정됩니다. 예측 정답의 변환, 예정 시각 등 다른 수치 입력의 스케일, RF 전처리, 손실 함수·가중치는 별도 협의합니다. 구체적인 스케일러 적합 대상 행과 중복 처리 등 구현 기준은 실행 전에 명시합니다.

## 근거와 한계

읽기 전용 확인에서 2024년 2호선 원본 366일·6,588행의 승차 중앙값은 435명, 최대는 13,775명이며, 하차 중앙값은 432명, 최대는 10,468명입니다. 최솟값은 각각 19명·58명으로 해당 범위에는 0명이 없습니다. 이는 분포 설명용 통계이며 실제 스케일러를 적합하거나 적용한 결과가 아닙니다.

표준화는 원래 인원 차이의 선형 관계를 유지하면서 신경망 입력 크기를 조정하는 초기 기준입니다. 큰 값이 평균·표준편차에 영향을 주고, 표준화 후에도 비대칭 분포와 큰 값은 남습니다. 정규분포로 바꾸는 처리가 아닙니다. 큰 값이라는 이유로 삭제·상한 절단하지 않습니다.

로그 변환 후 표준화는 후속 비교 후보입니다. 0의 유무와 로그 변환의 필요성은 별개입니다. 초기 검증 결과와 오차를 확인한 뒤 필요하면 사전 협의하여 비교하고, 전처리를 변경하면 모델도 다시 학습합니다. 최종 평가 자료로 전처리를 반복 선택하지 않습니다.

## DEC-016: 1차 신경망 MAE 손실

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

1차 MLP·LSTM은 원래 인원 단위의 MAE를 학습 손실로 사용합니다. 앞서 제안한 승차·하차·18개 시간대 동일 비중 평균을 기준으로, 각 표본의 36개 출력 절대오차를 평균하고 표본에 대해서도 동일 비중으로 평균합니다. 별도의 혼잡·경기·시간대 가중치를 추가하지 않습니다.

정답은 DEC-015에 따라 원래 인원 단위를 유지합니다. 모든 출력이 존재하는 현재 구성에서 이 손실은 승차 MAE와 하차 MAE의 평균과 일치합니다. RF의 트리 분할 기준은 신경망 손실과 별도 설정이며 이번 결정으로 확정하지 않습니다.

### 이유와 후속 검토

모델 선택 지표와 학습 목표를 맞추고 인원 단위로 설명하기 쉽습니다. 큰 오차를 제곱해 강조하지 않으므로 혼잡 시간대의 큰 오차가 충분히 줄어드는지는 별도로 확인합니다.

1차 학습 후 2025년 상반기 검증 성능과 오차 양상을 보고 유지 또는 MSE·Huber 등 후속 비교 여부를 협의합니다. 손실 변경은 자동으로 진행하지 않으며 비교 시 재학습합니다. 비교 조건과 변경 이유를 기록하고 하반기 최종 평가 자료로 손실을 반복 선택하지 않습니다.

### 사용자 답변

MAE 및 승차·하차·시간대 동일 비중 사용 제안에 다음과 같이 답했습니다.

> 일단 1차는 MAE로 진행하고 결과 보고 다시 선택하자

나머지 모델·학습 설정과 팀 검토 완료 전 학습하지 않습니다.

## DEC-017: 최대 학습 횟수와 검증 MAE 기준 조기 종료

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

1차 MLP·LSTM은 최대 에포크 수를 제한하고, 검증 MAE 개선 여부에 따른 조기 종료를 함께 사용합니다. 학습 종료 후 검증 MAE가 가장 낮았던 시점의 모델 가중치를 복원합니다. 최대 횟수에 도달하여 종료한 경우에도 동일하게 최선의 검증 모델을 사용합니다.

검증 기준은 DEC-006·DEC-016의 원래 인원 단위 승차·하차 평균 MAE입니다. 2025년 상반기 검증 자료를 사용하며 하반기 최종 평가 자료는 조기 종료에 사용하지 않습니다. 이 방식은 신경망에 관한 결정으로 RF에 자동 적용하지 않습니다.

### 이유와 한계

학습 오차만 계속 낮아지는 과적합과 불필요한 학습을 줄이기 위한 초기 운영 방식입니다. 조기 종료가 과적합 방지나 충분한 수렴을 보장하지는 않습니다. 학습·검증 곡선, 최선 에포크, 실제 종료 에포크, 종료 사유를 기록해 미수렴이나 일시적인 성능 정체를 확인합니다.

### 미정 사항

후속 결정 DEC-018에서 아래 세부 수치를 확정했습니다. 아래 문장은 본 결정 당시의 상태를 보존합니다.

최대 에포크 수, 개선을 기다릴 횟수(patience), 개선으로 인정할 최소 차이(min_delta), 검증 주기와 동점 처리 등의 세부 기준은 별도 협의합니다. 라이브러리 기본값을 자동 확정하지 않습니다. 최대 횟수까지 성능이 개선되어도 자동으로 학습 한도를 늘리지 않고 결과를 보고 협의합니다.

### 사용자 답변

최대 횟수와 검증 MAE 기준 조기 종료 및 최선 모델 복원 제안에 다음과 같이 답했습니다.

> 응 최대 횟수 조기 종료로 가자

설정 전체 결정과 팀 검토 완료 전 학습하지 않습니다.

## DEC-018: 1차 신경망 학습 횟수와 조기 종료 수치

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

DEC-017의 종료 방식을 다음 수치로 구체화합니다. 1차 MLP·LSTM의 3·7·14일 조건에 동일하게 적용합니다.

| 항목 | 설정 |
|---|---|
| 최대 에포크 | 200 |
| 검증 주기 | 매 에포크 종료 시 |
| 모니터링 지표 | 2025년 상반기 전체 검증 자료의 원래 인원 단위 승차·하차 평균 MAE |
| 개선 방향 | 감소 |
| patience | 20에포크 |
| min_delta | 0 |
| 종료 후 모델 | 검증 MAE 최저 시점의 가중치 복원 |

기존 최저 MAE보다 엄격히 낮을 때 개선으로 인정하고 기다림 횟수를 초기화합니다. 같은 값은 개선으로 인정하지 않으며 기존 최선 모델을 유지합니다. 20회 연속 개선이 없거나 최대 200에포크에 도달하면 종료합니다. 두 경우 모두 최선 모델을 복원합니다.

### 이유와 한계

200·20은 보편적인 최적값이 아니라 첫 실험의 출발점입니다. 100·10보다 학습과 일시적 정체를 관찰할 여유를 두되 조기 종료로 불필요한 반복을 제한합니다. min_delta 0은 인원 단위 최소 개선 폭을 임의로 추가하지 않는 선택이며, 미세한 개선이 반복되면 최대 횟수까지 학습할 수 있습니다.

원래 인원 단위 정답과 긴 LSTM 입력에서 충분히 수렴하는지는 학습률·배치 크기·구조에도 좌우됩니다. 학습·검증 MAE 곡선, 최선·종료 에포크, 종료 사유와 시간을 기록합니다. 상한까지 개선이 이어져도 자동 연장하지 않고 검증 결과를 보고 협의합니다. 최종 평가 자료는 종료나 수치 조정에 사용하지 않습니다.

### 사용자 답변

최대 200 / patience 20 / 매 에포크 검증 / min_delta 0 / 최선 모델 복원 제안에 다음과 같이 답했습니다.

> 응 일단은 그렇게 하자

RF에는 에포크·조기 종료 설정을 적용하지 않습니다. 나머지 설정과 팀 검토 완료 전 학습하지 않습니다.

## DEC-019: 1차 신경망 배치 크기 16

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

1차 MLP·LSTM의 학습 배치 크기는 16으로 설정합니다. 과거 3·7·14일 조건에 동일하게 적용합니다. 학습 사례 하나는 과거 기록과 예측일 부가 정보를 입력받아 다음 날 18개 시간대의 승차·하차 36개 값을 예측하는 묶음입니다. 16은 시간대 수나 과거 일수가 아닌 사례 수입니다.

현재 공통 학습 대상 352일을 모두 사용하면 1에포크당 22개 배치입니다. 각 배치의 평균 MAE를 바탕으로 가중치를 갱신합니다. RF에는 신경망 배치 크기를 적용하지 않습니다.

### 이유와 한계

작은 학습 자료에서 에포크당 갱신 기회를 확보하는 초기 설정입니다. 배치 크기 32의 11회보다 16은 22회 갱신하므로, 같은 에포크 수가 같은 갱신 횟수를 뜻하지 않습니다. 작은 배치는 갱신 방향의 변동이 커질 수 있으며 큰 배치보다 항상 빠르거나 성능이 좋다고 가정하지 않습니다.

검증 결과와 학습 시간·학습 곡선을 보고 변경 필요성을 협의합니다. 학습 사례 섞기, 시드, 최적화 알고리즘과 학습률은 이번 결정으로 자동 확정하지 않습니다. 각 사례 내부의 과거 시간대 순서는 DEC-012대로 유지합니다.

### 사용자 답변

MLP·LSTM 모두 배치 크기 16으로 시작하자는 제안에 다음과 같이 답했습니다.

> 응 일단 16으로 진행해줘

설정 전체 결정과 팀 검토 완료 전 학습하지 않습니다.

## DEC-020: 1차 Adam과 고정 학습률 0.001

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

1차 MLP·LSTM의 최적화 알고리즘은 Adam, 학습률은 0.001로 설정합니다. 3·7·14일 조건에 동일하게 적용하며 각 실행 중 학습률을 고정합니다. 학습률 스케줄러나 성능 정체에 따른 자동 학습률 감소는 사용하지 않습니다.

고정하는 것은 Adam의 기준 학습률입니다. 기울기 이력에 따른 가중치별 적응적 갱신은 Adam의 동작으로 유지됩니다. 학습률 0.001을 예측 인원의 0.1% 변화로 해석하지 않습니다.

### 이유와 한계

초기 최적값 탐색에 시간을 오래 쓰기보다 동일한 출발점으로 결과와 학습 곡선을 확보합니다. Adam은 기울기의 이력을 반영해 갱신 크기를 조절합니다. 0.001이 모든 모델에 최적이거나 200에포크 안에 충분한 수렴을 보장하는 값은 아닙니다.

학습·검증 MAE가 감소하지 않거나 크게 흔들리면 학습률·모델 구조·출력 규모 등을 함께 점검합니다. 학습이 충분하지 않은 결과만으로 모델 우열을 단정하지 않습니다. 변경은 검증 결과에 근거해 협의하고 재학습합니다.

### 범위와 미정 사항

이번 승인은 Adam 선택과 기준 학습률 및 실행 중 고정 정책입니다. 구현 라이브러리, beta 값·epsilon·weight decay 등 세부 설정은 기본값을 포함해 실행 전 명시하고 별도 협의합니다. AdamW나 추가 정규화를 자동 선택하지 않습니다. RF에는 적용하지 않습니다.

### 사용자 답변

Adam + 학습률 0.001 고정 제안에 다음과 같이 답했습니다.

> 응 일단 그렇게 진행하자

설정 전체 결정과 팀 검토 완료 전 학습하지 않습니다.

## DEC-021: 1차 모델 구조와 크기

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

### 결정

아래 구조 설정을 각 모델의 3·7·14일 조건에서 유지합니다. 모두 다음 날 18개 시간대의 승차·하차 36개 값을 예측합니다.

#### MLP

과거 승차·하차를 날짜·시간대·승하차 위치가 고정된 벡터로 펼치고 예측일 달력·경기 정보를 결합합니다. 과거 인원 값은 3·7·14일 각각 108·252·504개입니다.

결합 입력 → Dense 64(ReLU) → Dense 32(ReLU) → Dense 36(선형 출력).

#### LSTM

시간대별 승차·하차 2개 값 → LSTM 1층 32유닛 → 마지막 시점의 은닉 출력 32개 값에 예측일 달력·경기 정보 결합 → Dense 32(ReLU) → Dense 36(선형 출력).

입력은 DEC-012대로 54·126·252시점이며 결합 위치는 DEC-013의 A안입니다. 32유닛은 읽는 시간대 수가 아닌 내부 상태 크기입니다. Dense의 ReLU 결정을 LSTM 내부 활성화에 적용하지 않습니다.

#### 랜덤포레스트

MLP처럼 과거 기록을 펼친 값과 예측일 정보를 입력합니다. 하나의 다중 출력 RandomForestRegressor로 36개 값을 예측합니다.

- 트리 수(n_estimators): 200
- 최대 깊이(max_depth): 10
- 리프 최소 사례 수(min_samples_leaf): 3

### 이유와 한계

공통 학습 대상은 352일이므로 초기부터 깊은 신경망을 만들기보다 비교적 작은 구조로 기준 성능을 확인합니다. MLP는 입력 관계를 함께 처리하고, LSTM은 시간 흐름을 순차 처리합니다. RF는 여러 트리 예측을 평균하며 깊이·리프 크기로 지나치게 세세한 분할을 제한합니다. 작은 구조나 제한된 깊이가 충분한 학습 또는 과적합 방지를 보장하지 않습니다.

MLP는 과거 기간이 길어지면 첫 층의 파라미터 수가 증가합니다. LSTM은 같은 유닛 수에서 입력 시점 수가 늘어도 recurrent 층의 파라미터 수는 같지만 계산량은 늘어납니다. 실제 모델별 파라미터 수(신경망), 학습 시간, 학습·검증 성능을 기록하며 같은 구조 설정을 동일한 전체 모델 크기로 설명하지 않습니다.

### 아직 확정하지 않은 사항

선형 출력은 음수도 허용하므로 음수 예측 처리와 반올림은 별도 협의합니다. RF 분할 기준·나머지 세부값, RF 입력 스케일, 신경망 초기화·시드·추가 정규화, LSTM 내부 활성화·상태 처리 등의 실행 세부값은 자동 확정하지 않습니다. 기존 DEC-014의 신경망 과거 입력 표준화는 유지합니다.

> 응 일단 결과를 보고 튜닝이 가능한 것들은 임의로 정해줘

이후 조정 가능한 초기 하이퍼파라미터·구현 세부값은 매번 승인을 요청하지 않고 선택 이유와 값을 기록합니다. 이번 값들을 사용자가 개별 선택했다고 표시하지 않습니다. 기존 DEC-001~021의 합의는 유지합니다. 데이터 분할·입력 정보·예측 목표·평가 원칙 변경이나 팀 검토 전 학습 실행을 승인한 것으로 해석하지 않습니다.

### 예측값 처리

- 학습 손실은 보정 전 출력의 원래 인원 단위 MAE를 유지합니다.
- 최종 예측은 max(0, 예측값)으로 음수만 보정하고 소수점은 유지합니다. 상한 절단은 하지 않습니다.
- 조기 종료·최선 체크포인트·모델 선택은 보정 후 전체 검증 MAE로 통일합니다. 보정 전 MAE와 음수 출력 비율을 함께 기록합니다.
- 보고 화면에서만 반올림하고 저장 예측값과 평가에는 반올림하지 않습니다. 세 모델에 동일 적용합니다.
- 모든 정답이 0 이상이면 음수 보정은 MAE를 늘리지 않지만, 빈번한 음수 출력을 모델 문제로 점검합니다.

### 전처리

- 신경망 승차·하차는 각각 하나의 평균·모표준편차(ddof=0)로 표준화합니다. 2024년 2호선 원본의 고유 시간대 행 전체를 한 번씩 사용해 기준을 계산하며, 중첩 윈도 때문에 같은 행을 반복 집계하지 않습니다. 시간대·과거 위치별 별도 스케일러는 두지 않습니다. 동일 기준을 3·7·14일에 사용하고 2025년은 기준 계산에서 제외합니다. 표준편차가 0이면 분모 1로 처리하고 기록합니다.
- 신경망 예정 시각은 자정부터 분을 1,440으로 나눕니다. 계산용 빈칸 0과 존재 표시를 유지합니다. 원핫·이진 표시·경기 건수는 그대로 둡니다.
- RF에는 원래 인원·예정 분·건수를 사용하고, 같은 원핫·존재 표시를 제공합니다. 단조 선형 스케일 변경이 필요하지 않은 트리의 초기 기준입니다.
- 누락된 실제 인원·중복 키·비유한값·필수 시간대 누락은 임의 대체하지 않고 검증 실패로 보고합니다. 승인된 경기 기록 없음 표현과 구분합니다.

### 재현성과 학습

- 1차 시드 42, 조건별 학습 직전 난수 상태를 초기화합니다. 42 자체에 성능상의 의미는 없으며, 1차는 시드 하나이므로 반복 실험의 변동성을 검증했다고 주장하지 않습니다.
- 학습 사례의 순서는 매 에포크 섞고, 각 사례 내부의 과거 시간대 순서는 유지합니다. 검증·평가는 날짜 순서로 고정합니다. 분할 경계를 섞지 않습니다.
- LSTM은 단방향·비상태유지(stateful=False)이며 서로 다른 사례 사이에 은닉 상태를 전달하지 않습니다.
- 실행 프레임워크는 RF에 scikit-learn, 신경망에 Keras/TensorFlow를 초기 대상으로 선정합니다. 설치·버전 고정·장치 확인은 구현 단계에서 수행하고 환경 기록을 남깁니다. 현재 설치 완료를 뜻하지 않습니다.
- Dense 은닉층 가중치는 He normal, 선형 출력층은 Glorot uniform, Dense 편향은 0으로 초기화합니다. ReLU 은닉층과 선형 출력을 구분한 초기값입니다.
- LSTM은 tanh 상태 활성화·sigmoid 게이트, 입력 커널 Glorot uniform·순환 커널 orthogonal·편향 0 및 forget gate 편향 +1을 사용합니다.
- Adam은 beta1=0.9, beta2=0.999, epsilon=1e-7, amsgrad=False, weight decay 없음으로 명시합니다. 확정된 학습률 0.001을 유지합니다.
- Dropout·L1/L2·BatchNorm·gradient clipping은 1차에 사용하지 않습니다. 초기 변화 요인을 줄이고 학습/검증 곡선을 확인합니다. 비유한 손실은 실행 실패로 보고하며 자동으로 설정을 바꿔 재실행하지 않습니다.
- 실수 연산은 float32를 기준으로 하고 가능한 결정적 연산 설정과 장치를 기록합니다. 다른 하드웨어·라이브러리 버전에서 완전히 같은 결과를 보장하지 않습니다.

### RF 나머지 설정

- criterion=squared_error: 평균 예측을 사용하는 초기 기준으로 선택합니다. 큰 오차가 분할에 강하게 영향을 줄 수 있습니다. 신경망 MAE 학습과 다른 방식이며 RF의 최종 선택 지표도 MAE입니다.
- min_samples_split=2, max_features=1.0, bootstrap=True, max_samples=None, max_leaf_nodes=None, min_impurity_decrease=0, ccp_alpha=0, warm_start=False, oob_score=False, n_jobs=1, random_state=42.
- 트리별 학습 표본을 복원추출하고 모든 입력 특징을 분할 후보로 고려합니다. 초기 CPU 자원 사용을 제한하며 트리 200·깊이 10·리프 최소 3은 유지합니다. 구현 시 전체 실제 estimator 설정을 저장해 숨은 기본값을 확인합니다.

# DEC-001: 1차 대상 호선과 학습 모델

- 상태: 승인
- 날짜: 2026-11-02
- 결정자: 사용자
- 범위: 2024~2025년 2호선, 랜덤포레스트·MLP·LSTM 세 학습 모델

## 설명한 선택 근거

랜덤포레스트는 표 형태의 조건 관계, MLP는 기본 신경망의 비선형 학습, LSTM은 시간 순서 처리의 효과를 비교하기 위한 후보로 설명했습니다. 시간순 입력 처리 여부, 데이터 규모와 과적합, 설정 복잡성의 차이를 안내했습니다. Ridge·GRU·부스팅·1차원 CNN은 추가 후보로 소개했으나 이번에는 확정하지 않았습니다.

## 실제 사용자 답변

> 그럼 1차는 2호선으로 하고 랜덤포레스트, MLP, LSTM으로 진행하는데 왜 이 모델들을 선정하는지 더 추가할 모델은 없는지 알려줄래?

설명 후 최종 확인:

> 그럼 일단 세 모델로 진행하는 걸로 하자. 하나하나 차근차근 알려주면서 진행해줄래?

## 승인 범위와 다음 단계

위 대상과 세 모델의 비교 방향에 대한 승인입니다. 구체적인 예측 시점·출력, 입력 기간·변수, 분할, 지표, 하이퍼파라미터·손실 가중치 승인은 포함하지 않습니다. 학습은 아직 실행하지 않았습니다.

다음은 예측 시점과 출력 정의부터 한 항목씩 설명하고 확인합니다. 이후 입력, 평가 설계, 모델별 설정 순으로 협의합니다. 기존 데이터 검증 작업은 별도 `data/validate-inputs` 브랜치에 있습니다.

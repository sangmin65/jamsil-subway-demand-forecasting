# DEC-004: 시간순 분할과 기록 없는 날짜의 상태

- 상태: 승인
- 날짜: 2026-11-02
- 결정자: 사용자

## 결정

| 구간 | 예측 대상 날짜 |
|---|---|
| 학습 | 2024-01-01~2024-12-31 |
| 검증 | 2025-01-01~2025-06-30 |
| 최종 평가 | 2025-07-01~2025-12-31 |

세 모델·세 입력 기간의 비교 날짜는 공통으로 맞춥니다. 14일의 과거 기록 확보를 위해 학습 대상은 2024-01-15부터 시작합니다. 최종 평가에서는 기존 탐색 날짜 2025-09-25·26·27·28·30 및 2025-10-01을 별도 분리합니다. 추가 제외 전 대상 수는 학습 352일, 검증 181일, 평가 178일입니다.

분할은 예측 대상 날짜 기준입니다. 검증·평가 대상일보다 과거인 이전 구간의 관측은 입력으로 사용할 수 있습니다. 기존 탐색일의 과거 관측도 이후 날짜 예측 시 이미 알려진 기록으로 사용할 수 있으나 탐색일 자체는 최종 성능 집계에서 제외합니다. 전처리 기준은 학습 구간에만 맞춥니다.

**경기 기록이 없는 날은 미확인으로 유지합니다.** 이를 경기 없음 또는 비시즌으로 확정하거나 임의로 0으로 대체하지 않습니다. 미확인 상태의 구체적인 모델 입력 표현·결측 처리 방법은 별도 협의합니다.

## 승인 근거

시즌 구성·상태별 날짜 수와 분할의 장단점을 설명한 뒤 사용자가 답변했습니다.

> 응 그 분할로 확정하고 기록해줘. 경기 기록 없는 날은 미확인으로 남겨두고, 다음으로 결정해야 할 것도 장단점이랑 같이 설명해줘.

## 근거와 한계

[검토 보고서](../data_review.md#split-review)를 참고합니다. 각 구간에 경기 결과 기록일과 겨울 구간이 있으나 검증과 평가의 계절 구성은 다릅니다. 시즌 라벨과 원천 일정의 완전성은 아직 미검증입니다. 경기 상태는 사후 평가용 정보와 예측 당시 사용 가능한 정보를 구분해야 합니다.

## 미확정

모델 선택 지표, 상태별 집계·가중치, 입력 변수와 미확인 표현, 하이퍼파라미터·초기화·시드·손실 함수, 최종 모델 재학습 절차는 아직 승인하지 않았습니다. 학습은 실행하지 않았습니다.

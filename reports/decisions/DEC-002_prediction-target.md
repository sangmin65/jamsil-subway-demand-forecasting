# DEC-002: 예측 시점과 출력

- 상태: 승인
- 날짜: 2026-11-02
- 결정자: 사용자

## 결정

오늘 23~24시까지의 기록이 확보되었다고 가정하고 다음 날 06~24시의 18개 시간대별 승차·하차, 총 36개 값을 예측합니다. 랜덤포레스트·MLP·LSTM 모두 동일한 예측 대상을 사용합니다. 예측 대상일의 실제 승하차를 입력하지 않습니다.

## 설명한 장단점

다음 날 운영 준비라는 목적과 연결되고 하루 수요 곡선·경기 전후 피크를 비교하기 쉽습니다. 당일 관측으로 예측을 갱신하지 않으므로 돌발 상황 반영에는 한계가 있습니다. 매시간 다음 한 시간을 예측하는 대안은 최신 관측 활용이 가능하지만 구현과 데이터 가용성 조건이 달라집니다.

## 승인 근거

다음 날 36개 값 예측 방식 제안에 사용자가 답변했습니다.

> 응 그 방식으로 진행하자. 과거 며칠의 기록을 입력하는 게 좋을지 장단점이랑 같이 설명해줘.

## 한계와 미확정

실제 데이터 공개 시점은 검증하지 않았습니다. 우선 과거 자료를 이용한 모의 예측 실험입니다. 과거 입력 기간, 입력 표현과 부가 변수, 모델별 출력 구현, 분할·지표·학습 설정은 이번 승인 범위에 포함하지 않습니다.

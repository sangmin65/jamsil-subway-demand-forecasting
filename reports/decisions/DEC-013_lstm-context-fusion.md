# DEC-013: LSTM 과거 요약 후 예측일 정보 결합

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 미실행

## 결정

1차 LSTM은 과거 시간대별 승차·하차를 읽은 결과에 예측일 달력·경기 정보를 결합하는 A안을 사용합니다. 결합된 정보를 최종 예측 부분에 전달해 다음 날 시간대별 승차·하차를 예측합니다. 과거 입력 순서는 DEC-012를 따릅니다.

여기서 A/B는 부가 정보의 결합 위치를 뜻하며, DEC-012의 시간대별/날짜별 읽기 선택과 별개입니다.

## 이유와 한계

과거 이용량 처리와 예측일 조건의 역할을 구분해 설명하기 쉽고, 향후 다른 행사 정보를 결합 부분에 추가하기 수월합니다. 다만 LSTM이 과거 기록을 읽는 과정 자체에는 예측일 조건이 직접 입력되지 않습니다. 과거 요약은 단순 평균이 아닌 학습된 표현이며 경기 효과를 사람이 정한 가중치로 더하지 않습니다.

## 후속 비교 후보

B안은 동일한 예측일 달력·경기 정보를 모든 과거 시점에 반복해서 붙여 LSTM에 입력합니다. 예측일 조건이 과거 기록의 처리 과정부터 영향을 줄 수 있지만 입력 차원이 늘어납니다. 과거 해당 날짜의 경기 정보를 추가하는 것과는 다른 실험입니다.

후속 비교에서는 동일한 데이터 분할·대상 날짜·입력 정보·과거 기간·평가 지표를 사용하고, 합의한 학습 조건을 가능한 한 맞춥니다. 결합 위치에 따라 파라미터 수가 달라질 수 있으므로 모델 크기와 학습 시간도 기록합니다. A/B 선택·튜닝은 검증 자료로 수행하며 최종 평가 자료로 반복 선택하지 않습니다.

B안은 후속 실험 후보로 기록하며 이번 9개 기본 조합에 자동 추가하거나 실행하지 않습니다. 구체적인 비교 범위와 설정은 실행 전 별도 협의합니다.

## 사용자 답변

> A안으로 진행하고 후속으로 B안으로 비교군도 가능하다는거지?

정규화, 출력층 구성, 모델 크기, 손실 함수와 학습 설정은 미정입니다. 설정 전체와 팀 검토 완료 후 학습합니다.

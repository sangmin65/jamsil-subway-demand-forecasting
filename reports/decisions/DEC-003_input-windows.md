# DEC-003: 과거 입력 기간 3일·7일·14일 비교

- 상태: 승인
- 날짜: 2026-11-02
- 결정자: 사용자

## 결정

랜덤포레스트·MLP·LSTM 각각 과거 3일·7일·14일을 입력하는 총 9개 기본 조합을 비교합니다. 특정 기간을 최선으로 미리 확정하지 않습니다.

## 선택 근거와 장단점

- 3일: 최근 변화에 집중하고 입력이 작지만 지난주 같은 요일 기록이 없습니다.
- 7일: 일주일의 요일 구성을 포함하지만 같은 요일 관측은 한 번입니다.
- 14일: 같은 요일을 두 번 포함하지만 입력과 계산 부담이 커지고 불필요한 정보가 늘 수 있습니다.
- 세 기간을 비교하면 모델마다 필요한 과거 길이가 다른지 검증할 수 있습니다. 단, 성능 차이를 주간 주기의 효과만으로 단정하지 않습니다.
- 기본 조합이 9개로 늘어나므로 실행·분석 비용이 증가합니다. 경기 정보 포함/제외나 반복 시드는 이번 결정에 포함하지 않습니다.

## 사용자 승인

> 좋아. 3일·7일·14일 모두 비교하는 걸로 기록하고 커밋해줘. 다음으로 결정해야 할 건 뭐야? 장단점이랑 같이 설명해줘.

## 비교 설계 원칙

같은 대상 날짜·정보·평가 지표를 사용하도록 설계합니다. 입력 기간 외 주요 설정은 모델 내에서 가능한 한 동일하게 맞추고, 입력 크기에 따른 파라미터 수 차이를 기록합니다. 먼저 한 조합의 데이터 흐름을 점검한 뒤 나머지 조합에 적용합니다. 초기 점검에 사용할 설정도 사전 협의 대상입니다.

## 미확정

학습·검증·최종 평가 날짜, 선택 지표, 입력 변수·결측 처리, 모델별 하이퍼파라미터·시드·손실 가중치는 아직 결정하지 않았습니다. 모델 학습은 실행하지 않았습니다.

# DEC-006: 모델 선택 지표 A안

- 날짜: 2026-11-02
- 상태: 사용자 선택 완료 / 팀 검토 대기 / 학습 실행 승인 전

## 선택

2025년 상반기 공통 검증 날짜의 원래 인원 단위에서 다음 점수를 계산합니다.

`selection_score = (boarding_MAE + alighting_MAE) / 2`

각 MAE는 동일한 날짜의 18개 시간대 전체 절대오차 평균입니다. 점수가 낮은 모델·입력 기간 조합을 우선 선택합니다. 승차·하차 RMSE, 월별 및 note 상태별 성능·표본 수는 함께 보고하되 사후에 주 지표를 바꾸지 않습니다. 미확인일도 이용량 정답이 있으면 전체 평가에 포함합니다.

## 근거와 한계

평균 몇 명 틀리는지 설명하기 쉽고 야구 외 행사로 확장할 때도 동일한 기준을 사용할 수 있습니다. MAE 자체가 새로운 행사에서의 일반화를 보장하지는 않습니다. 일부 큰 오차가 전체 평균에 가려질 수 있어 보조 지표를 함께 봅니다.

## 사용자 답변

> A로 가야 확장하기 좋은거니까 A로 가자

## 승인 범위

평가 기준에 대한 사용자 선택입니다. 팀 검토 후 내일 실행하는 일정에 따라 아직 학습하지 않습니다. 학습 손실·조기 종료 지표·가중치·동점 처리·모델 설정은 별도 협의합니다.

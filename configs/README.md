# 실험 설정

`initial.json`은 DEC-001~022와 연결한 1차 설정입니다. 팀 검토는 아직 미완료이므로 `team_review.approved`는 false입니다. 사전 점검은 가능하지만 학습 명령은 실제 검토 정보가 기록되기 전 차단됩니다.

실험·결정 ID, 데이터 버전, 호선, 입력·출력, 분할 날짜, 변수·전처리, 모델 설정, 손실·가중치, 시드, 지표를 명시합니다. 주요 라이브러리 기본값도 설명합니다. 미승인 값을 실행 가능한 기본값으로 추가하지 않습니다.

초기 수치 변경은 이 파일에, 전처리·초기화·출력 정책 변경은 관련 코드와 결정 기록에 반영합니다. 실제 실행은 설정 사본·원본 해시·코드 해시·환경·입력 특징과 모델 구성을 출력 폴더에 저장합니다. 명령은 `docs/RUNBOOK.md`를 참고하세요.

# 종합운동장역 지하철 수요 예측

2024~2025년 종합운동장역 승하차 및 KBO 경기 데이터를 활용한 인공지능공학 팀 프로젝트입니다. 여러 모델을 비교해 다음 날 시간대별 승차·하차 수요를 예측합니다.

## 목표와 상태

- 야구 입력은 수집 기록 유무·건수, 경기 1·2 예정 시각과 홈팀·원정팀입니다. 별도 인기도 점수와 note·gamecenter_status는 입력에서 제외합니다. 표현 방식은 협의 중입니다.
- 1차 달력 입력은 요일·월·공휴일 여부(B안)로 사용자 선택 완료, 팀 검토 대기입니다. 공휴일 참조 목록은 `data/reference/holidays_2024_2025.json`에 있습니다.
- 1차는 확보한 야구 정보를 중심으로 진행합니다. 콘서트·다른 행사 정보는 향후 발전 계획이며, 야구 경기일만으로 날짜를 제한하지 않습니다.
- 데이터 기간: **2024-01-01~2025-12-31** (합의 완료)
- **2026-11-04 수요일까지 1차 실행**, 부족한 자료는 이후 보충합니다.
- 여러 모델의 검증 성능을 비교해 최종 모델을 선택합니다.
- 1차 대상은 **2호선**, 학습 모델은 **랜덤포레스트·MLP·LSTM**으로 확정했습니다. 추가 학습 모델은 보류합니다.
- 오늘 23~24시까지 기록 확보를 가정하고 다음 날 06~24시의 승차·하차 총 36개 값을 예측합니다. 실제 자료 공개 지연은 미검증입니다.
- 과거 **3일·7일·14일**을 세 모델에 각각 적용해 총 **9개 기본 조합**을 비교합니다.
- 분할: **2024년 학습 / 2025년 상반기 검증 / 하반기 최종 평가**. 공통 과거 입력과 탐색일 제외 적용 후 대상은 352/181/178일입니다.
- 경기 기록이 없는 날짜는 **미확인**으로 유지합니다.
- 모델 선택은 전체 검증 날짜의 승차·하차 평균 MAE(A안)로 사용자 선택 완료, 팀 검토 대기입니다. RMSE·월별·note 상태별 성능도 보고합니다.
- 입력 변수, 기준 예측 구성, 파라미터·손실 가중치는 설명과 사용자 답변 후 확정합니다. 전체 설정의 팀 검토 후 학습합니다.
- 현재는 기본 구조·운영 문서 준비 단계입니다. 학습 코드·모델·측정된 성능은 없습니다.

## 시작 순서

1. [협업 규칙](CONTRIBUTING.md)과 [실험 원칙](docs/EXPERIMENT_POLICY.md)을 읽습니다.
2. [데이터 안내](data/README.md)에 따라 원본을 준비합니다. 아직 이 저장소에 복사하지 않았습니다.
3. Python·패키지·CPU/GPU 환경을 확인하고 [환경 양식](docs/templates/ENVIRONMENT_TEMPLATE.md)에 기록합니다. 패키지 버전과 설치 방법은 아직 확정하지 않았습니다.
4. 모델·분할·지표·설정을 협의하고 [결정 양식](docs/templates/DECISION_TEMPLATE.md)에 남깁니다.
5. 승인된 조건으로 구현·실행하고 [실험 양식](docs/templates/EXPERIMENT_TEMPLATE.md)에 실제 결과를 기록합니다.
